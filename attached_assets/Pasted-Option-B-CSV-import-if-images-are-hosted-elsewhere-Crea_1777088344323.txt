3.2 Run a quick duplicate/mismatch check
Use this Python script (you can drop it into the Replit project or WSL):

python
import csv
from collections import defaultdict

by_sku = defaultdict(list)
by_title = defaultdict(list)
by_image = defaultdict(list)

with open("products_export.csv", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    rows = list(reader)

for row in rows:
    sku = row["sku"].strip()
    title = row["title"].strip().lower()
    image = row["image_url"].strip().lower()

    by_sku[sku].append(row)
    by_title[title].append(row)
    by_image[image].append(row)

def report(label, groups):
    print(f"\n=== POSSIBLE DUPLICATES BY {label} ===")
    for key, items in groups.items():
        if key and len(items) > 1:
            print(f"\n{label}: {key!r}  (count={len(items)})")
            for r in items:
                print(f"  - SKU={r['sku']} | Title={r['title']} | Image={r['image_url']} | Price={r.get('price')}")

report("SKU", by_sku)
report("TITLE", by_title)
report("IMAGE", by_image)
This gives you:

Duplicate SKUs → must be merged or corrected.

Duplicate titles → check if they’re truly distinct products.

Duplicate images → same image used for multiple SKUs; verify that’s intentional.
