1. Batch format for your entire operator catalog
All operators go into one JSON array, each item using the same template:

json
[
  {
    "product_name": "",
    "sku": "",
    "price": 0,
    "category": "Window Operators",
    "description_short": "",
    "description_long": "",
    "images": [],
    "attributes": {
      "operator_type": [],
      "handing": [],
      "arm_length": [],
      "color": [],
      "mount_type": [],
      "cover_style": [],
      "handle_type": [],
      "brand_compatibility": []
    },
    "sold_as": "Each",
    "notes": []
  }
]
That’s your master shape. Every operator record just fills those fields.
